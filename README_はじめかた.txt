STUDY NOTE（勉強アプリ）の使い方

このフォルダには、勉強時間・小学6年生クイズ・ごほうび機能をまとめたアプリが入っています。

大事なこと：
このファイルをダウンロードしただけでは、Androidのホーム画面に「アプリ」として追加する準備はまだ完了していません。ホーム画面に追加するには、インターネット上の安全なページ（https://で始まるページ）に置く必要があります。

いちばん簡単な次の手順：
1. このZIPファイルを解凍（中身を取り出す）します。
2. 中のファイルを、HTTPSで公開できる場所にアップロードします。例：GitHub Pages（無料ですが、アカウント作成などの設定が必要です）。
3. 公開されたURLをAndroidスマホのChromeで開きます。
4. Chrome右上の「︙」を押します。
5. 「ホーム画面に追加」または「アプリをインストール」を押します。
6. 「追加」を押すと、ホーム画面にアイコンができます。

ひとりで設定するのが難しかったら、保護者や信頼できる大人に手伝ってもらってね。公開用アカウントに住所・学校名などの個人情報は書かないでください。

機能：
- 15分・25分・45分の勉強タイマー
- 小学6年生向けの算数・国語・理科・社会クイズ10問
- 25分勉強するごとにもらえるアプリ内ごほうび
- やることリスト
- 勉強時間・ごほうびの記録（同じブラウザ内に保存）
- いったん読み込めば、基本画面をオフラインでも開けるようにする仕組み

注意：
- データはこの端末のブラウザに保存されます。ブラウザのデータを消すと記録も消えることがあります。
- このアプリは個人用の試作品です。ストア配信のAndroidアプリ（APK）ではありません。
